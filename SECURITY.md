# Security policy

This portfolio repository intentionally excludes production credentials,
infrastructure details, operational tooling, and write-capable administration APIs.

Please report a suspected vulnerability privately to **security@example.invalid**.
Do not open a public issue containing exploit details, credentials, or personal data.
The address is intentionally a placeholder in this portfolio edition; evaluators may
contact the repository owner through the private contact method shown on the owner's
GitHub profile.

Only the latest revision of this portfolio edition is supported. The private
commercial application and its infrastructure are outside this repository's scope.
